# SetPeta | セトピタ

YouTubeで再生したカラオケ音源を検知し、配信のセトリ用タイムスタンプを自動で記録するChrome拡張機能です。

## インストール

通常はChromeウェブストアからインストールできます。

**[Chromeウェブストアで「セトピタ」をインストール](https://chromewebstore.google.com/detail/SetPeta-%E3%82%BB%E3%83%88%E3%83%94%E3%82%BF/caajbfckihllgmbgannehljfabddabhg)**

### GitHubから手動でインストールする場合

この拡張機能はビルド不要です。GitHubからダウンロードして、そのままChromeに読み込めます。

1. GitHubの「Code」→「Download ZIP」を選ぶ
2. ダウンロードしたZIPファイルを展開する
3. Chromeで `chrome://extensions` を開く
4. 右上の「デベロッパーモード」をオンにする
5. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
6. 展開したフォルダ内の `extension` フォルダを選ぶ

初回読み込み時に「はじめに」が開きます。ブラウザ右上の拡張機能アイコン（パズルのピース）からセトピタをツールバーに固定しておくと、いつでもサイドパネルを開けます。

## 使い方

1. YouTubeでカラオケ音源を再生すると、再生時刻・動画タイトル・URLが自動で記録されます
2. 配信終了後、アーカイブで1曲目の開始時刻を確認してサイドパネルに入力します
3. 「セトリ生成」を押し、作成されたテキストをコピーして概要欄などに貼り付けます

## 対応ブラウザ

Google Chromeの最新版を推奨します。
