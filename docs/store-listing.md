# Chrome Web Store 掲載用テキスト(下書き)

## 拡張機能名
SetPita | セトピタ

## 概要(132文字以内)
YouTube歌枠配信のカラオケ音源再生を自動検知し、タイムスタンプ付きセトリを自動生成するツール

## 詳細説明
Setpetaは、YouTubeで歌枠配信をする配信者向けのChrome拡張機能です。

配信中にカラオケ音源(YouTube動画)を再生するたびに、再生開始時刻・動画タイトル・URLを自動で記録します。配信終了後、アーカイブで1曲目が実際に始まった時刻を1回入力するだけで、タイムスタンプ付きのセトリテキストを自動生成します。

【主な機能】
・YouTube上でのカラオケ音源再生を自動検知(手動操作不要)
・再生中/停止中の状態をリアルタイム表示
・自動再生(前の曲からの流れ)かどうかを推定して表示
・ログの手動編集・削除に対応
・アーカイブ基準のタイムスタンプ付きセトリを自動生成、ワンクリックでコピー
・一定時間操作がなければログを自動リセット(設定で変更可能)

【プライバシーについて】
記録したデータはすべてブラウザ内(ローカル)にのみ保存され、外部のサーバーには一切送信されません。

## 権限の説明(審査時に聞かれる項目)

### host_permissions: *://www.youtube.com/*
カラオケ音源として再生されているYouTube動画の再生開始・停止、タイトル、URLを検知するために必要です。YouTube以外のサイトにはアクセスしません。

### storage
検知したログ・生成したセトリ・設定値をブラウザ内にローカル保存するために使用します。外部送信は行いません。

### sidePanel
記録したログの確認・編集や、セトリ生成の操作を行うUIをサイドパネルとして表示するために使用します。

## 単一の目的の説明(Single purpose)
YouTube上でのカラオケ音源再生を検知してタイムスタンプを記録し、配信アーカイブ向けのセトリ(タイムスタンプ付き楽曲リスト)を生成すること。
