# 開発環境・ビルド・テスト手順

Chrome拡張機能の開発が初めてでも迷わないように、必要な作業を順番にまとめます。
このツールはビルド不要(素のJS/HTML/CSSのみ)なので、Node.jsやnpmは不要です。

## 1. 必要なもの

- Google Chrome(最新版)
- コードエディタ(VSCodeなど。何でもOK)
- 以上。Node.js等のビルドツールは不要です

## 2. ディレクトリ構成

```
extension/
├── manifest.json      拡張機能の設定ファイル(必須)
├── background.js      裏で動き続けるスクリプト(ログの保存・管理)
├── content.js         YouTubeページに注入されるスクリプト(再生検知)
├── popup.html          拡張アイコンを押した時に開くUI
└── popup.js            popup.htmlの動作ロジック
```

## 3. 拡張機能をChromeに読み込む(「ビルド」に相当する作業)

このプロジェクトはビルドという概念がなく、フォルダをそのままChromeに読み込むだけで動きます。

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」ボタンをクリック
4. `extension/` フォルダを選択する
5. 拡張一覧に「Setpeta」が表示されればOK

## 4. コードを変更したら

`chrome://extensions` の該当拡張のカードにある**リロードボタン(circular arrow)**を押すと変更が反映されます。
YouTubeタブを開いていた場合、content.jsの変更を反映するには**タブ自体もリロード**してください
(background.js・popup.jsの変更は拡張のリロードだけで反映されます)。

## 5. 動作確認・デバッグ方法

### content.js(YouTubeページ側)のデバッグ
1. YouTubeの動画ページを開く
2. F12でDevToolsを開き、Consoleタブを見る
3. `console.log`を仕込んでおけば、ここに出力される
4. 動画を再生し、再生検知のログが出るか確認する

### background.js(service worker)のデバッグ
1. `chrome://extensions` を開く
2. Setpetaのカードにある「service worker」というリンクをクリック
3. 専用のDevToolsが開き、background.js用のConsoleが見られる
4. ここでの`console.log`やエラーもここに出る

### popup.jsのデバッグ
1. 拡張アイコンをクリックしてポップアップを開く
2. ポップアップ内で右クリック →「検証」を選ぶとDevToolsが開く
   (ポップアップは閉じるとDevToolsも一緒に閉じるので、開いたままデバッグする)

### chrome.storageの中身を直接確認したい場合
background.jsのDevTools Consoleで以下を実行すると中身が見える:
```js
chrome.storage.local.get(null, console.log)
```

## 6. 手動テストのシナリオ(最低限これを確認する)

1. **記録対象タブの指定**: YouTube動画ページでポップアップを開き、「このタブを記録対象にする」を押す → 指定が反映されるか
2. **再生検知**: 指定したタブで動画を再生 → ポップアップのログに時刻+タイトルが追加されるか
3. **複数回再生**: 同じ動画を一時停止→頭出し→再生、を繰り返す → その都度ログが追加されるか(意図通り、間引かれずに全部残る)
4. **無関係タブの除外**: 記録対象に指定していない別のYouTubeタブで動画を再生 → ログに追加されないか
5. **ポップアップを閉じても記録継続**: ポップアップを閉じた状態で動画を再生 → 開き直したときにログが増えているか
6. **ログの手動編集・削除**: 誤ったログを削除・曲名を修正できるか
7. **セトリ生成**: 「1曲目のアーカイブ開始時刻」を入力してセトリ生成 → タイムスタンプが正しくオフセットされているか
8. **コピー機能**: 生成結果をコピーボタンでクリップボードにコピーできるか

## 7. 配布(自分用/将来の公開)

- **自分だけで使う場合**: 上記の「パッケージ化されていない拡張機能を読み込む」手順だけで十分。以降も不要
- **将来Web Storeで公開する場合**: 別途Chrome Web Store Developer Dashboardへの登録($5の一回払い)、
  プライバシーポリシーの用意、審査提出が必要になる(このdocsでは扱わない。公開を検討する段になったら別途まとめる)
